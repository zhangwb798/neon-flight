# NEON FLIGHT

一个无需安装、打开浏览器即可玩的极简霓虹 2D 飞机射击原型。

## 运行

直接双击 `index.html`。如果浏览器限制本地文件，也可以在本目录启动任意静态文件服务器。

## 操作

- 鼠标或触摸拖动飞机
- WASD / 方向键移动
- 自动射击
- 主界面可选择简单、普通、困难、地狱四档难度；敌人速度、血量、密度、障碍频率和结算奖励会随难度变化
- 击碎物体收集经验
- 升级时三选一
- 可在整个屏幕内自由移动
- 蓝灰色双层线框障碍带有“X”核心，无法被子弹击毁，只能躲避；它使用独立计时器稳定生成，不受目标皮肤影响
- 与目标碰撞即结束；护盾可以抵消一次碰撞
- 右上角齿轮可以随时暂停、切换打击感反馈或放弃本局返回主界面

## 已实现

- 霓虹线框、滚动网格和雷达刻度
- 三种目标等级及动态血条
- 不可破坏障碍，以及随生存时间明显加快的整体速度
- 命中闪白、缩放、屏幕震动和命中停顿
- 线段碎裂、冲击波、经验吸取和合成音效
- 11 种强化后的可叠加升级，包含扩大经验吸取范围
- 桌面与触屏控制
- 每局结算能量晶体，可在机库商店购买并装备 18 种战机、子弹和目标皮肤
- 付费皮肤拥有独立轮廓和动态，包括幽灵折翼、棱镜三角、日蚀之环、电弧、零点光环、彗星、虚空、电路和生物形态
- 商店可购买有库存上限的一次性战备：护盾、火力芯片、经验电池和开局升级三选一，每局开始自动消耗一份
- 粒子、子弹、经验体与音频声部设有动态上限，碰撞检测和 HUD 刷新已做轻量化，缓解长局和高射速时的卡顿
- 历史档案保存总局数、最佳时间、最高等级、累计击碎和最近五局

## 本地存档

能量晶体、难度、战备库存、已购买皮肤、当前装备、打击感设置和历史档案使用浏览器 `localStorage` 保存在本机。清除该页面的浏览器站点数据会同时清除存档。

全部图形均由 Canvas 实时绘制，没有使用外部图片或字体资源。
